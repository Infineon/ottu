Contributing
============

Thanks for your interest in contributing to ottu!

We welcome improvements of all sizes, from typo fixes to new features. The best
way to start is to align early with the maintainers so everyone agrees on scope,
intent, and approach.

1. Start by aligning on scope through a GitHub `issue <https://github.com/Infineon/ottu/issues>`_ or `discussion <https://github.com/Infineon/ottu/discussions>`_.
2. Set up your local environment using the :doc:`dev-setup` guide.
3. Follow the coding, commit message, and validation requirements in :doc:`conventions`.
4. Ensure your changes pass the :doc:`ci` checks.
5. Familiarize yourself with :doc:`index` and update docs when behavior changes.
6. Follow the `Code of Conduct <https://github.com/Infineon/ottu/blob/main/CODE_OF_CONDUCT.md>`_ in all interactions.
7. Submit your changes via a GitHub `pull request <https://github.com/Infineon/ottu/pulls>`_.
8. Be ready to iterate on your changes based on feedback from maintainers and the community.
9. Celebrate your contribution and be proud of your impact on the project!
