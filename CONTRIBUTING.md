# Contributing

We welcome contributions to this project. Before opening a pull request, please
start by discussing the change in the relevant GitHub [issue](https://github.com/Infineon/ottu/issues)
or [discussion](https://github.com/Infineon/ottu/discussions) so the maintainers
and contributors can align on scope, intent, and approach.

See [docs/devs-get-started.md](docs/devs-get-started.md) for developer setup,
local run, and test instructions.

## Before opening a PR

- Open or join the relevant issue or discussion and confirm the change is aligned
  with the project's direction.
- Keep the scope focused on the problem being solved.
- Follow the repository conventions and coding style used in the codebase.
- Ensure your changes pass the project's CI checks and validation steps.
- Respect the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md).

## Contribution expectations

- Make sure your patch is well-tested and documented where needed.
- Keep discussions constructive and respectful.
- Be prepared to revise your proposal based on maintainer feedback.
